# Smartwatch Prototype

Quick prototype to demo smartwatch interactions in the browser using React + CSS variables.

How to run

1. Open [index.html](index.html) in Safari on your Mac (File → Open File...).
2. Use Safari's Responsive Design Mode (Develop → Enter Responsive Design Mode) and choose an iPhone profile (e.g., iPhone 16 Pro) to prototype in the phone viewport.
3. Interact with the dropdown to change the simulated watch screen size; font sizes and buttons scale automatically.

Notes

- The page uses CDNs for React and Babel so it runs without bundling.
- Edit `PRESETS` in `app.js` to add or tweak device sizes and scale factors.
